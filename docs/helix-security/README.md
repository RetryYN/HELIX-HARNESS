# HELIX-SECURITY

親は[HELIX Concept](../concept/helix-concept.md)である。HELIX-SECURITYは、HELIX、利用者、各projectの資産に対する信頼の境界と資産の境界を持つ機構である。
HELIX-SECURITYの企画（L1）は、2026-09-26にPOが示した原文をもとにした案である（[判断記録](../governance/decisions/security-l1-idea-po-decisions-2026-09-26.md)）。

| 入口 | 内容と状態 |
|---|---|
| [L1企画案](L1-planning/security-intent.md) | POの原文をもとにした案。POが対象revisionを確認する |
| [POの原文（2026-09-26）](sources/security-l1-idea-po-original-2026-09-26.md) | 書き換えない原文の保存 |

現行のHELIX-OSとHELIX-HARNESSの要求案にある旧SEA（Security engagement）の条件は、それぞれの文書で再採否待ちである。L1企画案のrevisionをPOが確認した後に、SECURITYの要求（L2）として採否する。
