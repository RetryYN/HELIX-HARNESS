## 根拠の読み方と留保

- 各parent rowはindexのidentity/fixed L2 locatorとaudit refsを対応させ、snapshot bodyの実SHA-256を確認した。raw snapshotがindex登録SHAと一致した。
- 「根拠付き限定読了結論あり」は、原監査本文/JSONが親別に固定親、6本文の対象箇所、CASE群、または意味結論を記述している場合に限る。たとえば INTELLIGENCE Stage 3の22親ごとのnote、Stage 5 060–063のCASE/normal/negative/owner記述、LABO 064–067のparentごとの6文書spanとfindingsが該当する。
- 「元監査に親は含まれるが結論は限定・不明」は、親名/CASE IDの列挙やdigest pinはあるが、親別の結論/旧sourceの直接範囲が弱いもの、または旧sourceが前監査参照・部分読みと明記されたもの。ここでも対象本文全体の未監査を「未監査親」と混同しない。
- 4機構では各親に少なくとも一つのoriginal semantic review refがあり、厳密な「scopeに親が存在しない」例は見当たらなかった。そのため「実未監査source不足」は0件。ただし、この0は完全なold-source/consumer reviewを意味しない。
