# PLAN-RECOVERY-1378: startup authority consumer投影

## 目的

本体で修正済みのstartup authorityとhook境界をsetup consumerへ決定的に伝播し、古いread order、roster、blocked/degraded capabilityを新しいconsumerへactive guidanceとして再配布しない。

## 第一slice

1. source-owned startup packetを既存setup template catalogへ登録する。
2. clean consumerへ`.helix/startup/effective-agent-startup.json`を生成する。
3. source/template/generated bytesのSHA-256を別々に計測し、完全一致をproduction readinessで強制する。
4. read order、hook surface、roster、capability state/guidanceを同じverifierで検証する。
5. clean setup rendererとmutation反例で実効経路を拘束する。

## 残義務

- #1215 ownerでClaude memory wake本体をbounded lifecycleへ収束する。
- #863/#864 ownerでlegacy team engineのconsumer 0、後継E2E、rollback後に物理artifactを退役する。
- #1370 aggregateでRequirement IR、workflow、worker-contextを一つのcompiled startup packetへ合成する。
- distribution tag/cutoverと実consumer read-afterは既存release/action-binding境界で閉じる。

本PLANはdraftであり、第一sliceの実装・局所検証・draft PRを記録する。独立review、full CI、merge、main read-after前にcompletionを主張しない。
