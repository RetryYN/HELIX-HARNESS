# HELIX-INFRASTRUCTURE

親は[HELIX Concept](../concept/helix-concept.md)である。HELIX-INFRASTRUCTUREは、HELIX自身の実行基盤（計算、network、保存先、Workerとモデルの実行環境等）の実際の状態を持つコア機構である。
2026-09-26にPOが示した原文をもとにL1企画案を作り（[判断記録](../governance/decisions/infrastructure-l1-idea-po-decisions-2026-09-26.md)）、同日のPOの回答で、Conceptの機構の表に加えた（「9つの機構と1つの共通部品」）。1.0は原文の「1.0で最低限成立させる範囲」の18項目、高度なAutoscaling・Multi-cloud・完全自動のFailover等は後の版とする（[Concept配置の判断記録](../governance/decisions/infrastructure-concept-placement-po-decisions-2026-09-26.md)）。
