# HELIX Concept入口

版ごとに別ファイルを作らず、同じファイルをその場で改訂する。改訂は人の指示をAIが反映し、本文冒頭の改訂履歴へ記録する。
Conceptを改訂したら、紐づく下位文書を見直し対象として示す。見直しを理由に作業全体を止めない。
