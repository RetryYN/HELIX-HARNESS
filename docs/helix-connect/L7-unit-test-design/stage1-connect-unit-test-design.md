## 2. fixtureの読み方

`IV-CONNECT-*`は既存L9が定義したoracle IDであり、この表では対応参照に留める。`L5 API / L6 locator`が「APIなし」となる行はL8/L9のnegative boundaryまたは局所holdであり、テスト用の架空APIを追加しない。`baseline`、`一つの変異またはpositive control`、`期待oracle`の各列はL8の同名列を保持する。API呼出しの戻り型と、L9が判定するK1/K2/domain oracleは別の境界として解釈する。
