このフォルダは、HELIX-WebとHELIX-Web-OSの文書の置き場所である。HELIX本体（Concept、HARNESS、OS等）の文書は
[docs/](../docs/README.md)に置き、Web側の文書と分ける（2026-09-26のPO判断、[配置の判断記録](../docs/governance/decisions/helix-web-relocation-po-decisions-2026-09-26.md)）。

| 対象 | 属性 | 文書 |
|---|---|---|
| HELIX-Web | 外部提供する製品 | [入口](docs/helix-web/README.md) |

親は、HELIX本体の[HELIX Concept](../docs/concept/helix-concept.md)である。
両者のL1・L2・L11は、2026-09-24のPO判断でVisionレベルの材料へ分類し直した
（[decision record](../docs/governance/decisions/concept-requirement-po-decisions-2026-09-24.md)）。要求は今後POの指示から起こす。

置き場所を移しただけであり、各文書の本文の意味、分類、authority状態は変えていない。
