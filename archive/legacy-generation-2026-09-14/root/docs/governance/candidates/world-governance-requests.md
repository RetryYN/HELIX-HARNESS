# 全体機能統制の要求候補

#1500のCapability／Release Portfolio Managementを拡張する。Worldは本repositoryと許可済みconsumer／配布境界であり、外部世界一般ではない。

- HWG-BR-01: 既存の全機能を要求・責務・実装・検証・利用・提供の両方向から追跡でき、未把握を隠さない。HWG-R01／R02／R03へ分解する。
- HWG-BR-02: 新しい要求を自由に受け付けながら、既存機能との接続と行為ごとの必要条件を確認し、無関係な開発を止めずに拡張できる。HWG-R04／R05／R07／R08へ分解する。
- HWG-BR-03: 利用可能な機能を独立した提供単位として届け、統制コストも測りながら段階導入できる。HWG-R06／R09へ分解する。

現行の意味正本はcanonical Requirement JSON。以下のMarkdownは未承認の変更候補であり、current JSONと二重正本にしない。承認・独立検収・正規更新・main read-after・#397 IR admissionを経て初めてruntimeへ投影する。
全件棚卸しの対象にはHWG自身を含む。「全部統制する」は一括実装・一括停止・既存policy解除の許可ではない。
